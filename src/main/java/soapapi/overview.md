# SOAP API - Web Services

## Overview
SOAP (Simple Object Access Protocol) is a protocol for exchanging structured information in web services.

## Key Topics
- WSDL (Web Services Description Language)
- SOAP requests and responses
- XML parsing
- Web service client creation
- Service testing

## Key Differences from REST
- Uses XML exclusively
- More formal specification
- Built-in error handling (SOAP Faults)
- WSDL provides service contract

## Setup
1. Add SOAP/WebService dependencies to pom.xml
2. Generate client from WSDL (wsimport or Apache CXF)
3. Create service clients

## Common Use Cases
- Enterprise web service integration
- Legacy system communication
- SOAP service testing
- Secure service communication
