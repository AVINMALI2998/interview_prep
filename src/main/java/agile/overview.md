# Agile Testing - Overview

## What is Agile Testing?
Agile testing is an approach to software testing that aligns with the principles and practices of Agile software development.

## Key Characteristics
- Testing integrated throughout development
- Continuous feedback
- Collaborative approach
- Iterative testing
- Adaptive to change

## Skills You'll Learn
- Agile methodologies (Scrum, Kanban)
- Sprint-based testing
- Test automation in CI/CD
- BDD and TDD approaches
- Agile metrics and reporting
- Team collaboration techniques

## Why Learn Agile Testing?
- Most companies now use Agile
- Faster feedback and delivery
- Better quality through continuous testing
- Team collaboration skills
- Career advancement opportunities

## Course Structure
- Agile Fundamentals
- Scrum & Kanban Frameworks
- Testing in Agile Projects
- Automation & CI/CD
- Team Dynamics & Scaling
- Real-world Project Experience

## Prerequisites
- Basic understanding of software testing
- Familiarity with software development concepts

## Time Commitment
- 60 days with 2-3 hours daily practice
- Can be accelerated or extended based on learning pace
