
How to handle dropDown in selenium

WebElement dropDown = driver.findElement(By.xpath());
Select s = new Select(dropDown);

Select methods

s.selectByValue("India");
s.selectByVisibleText("Hello");
s.selectByIndex(2);

Deselect Methods
s.deselectByValue("hello");
s.deselectByVisibleText("demo");
s.deselectByIndex(2);
s.deselectAll();
